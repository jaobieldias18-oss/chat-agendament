# Chat Agendamento — Atendente Virtual

App de atendente virtual de agendamento para pequeno negócio.

O cliente final conversa com o chatbot pelo chat para ver horários livres e marcar um atendimento, com respostas curtas e diretas, como numa conversa de WhatsApp.

## Stack

- **Backend:** Supabase
- **IA:** Groq
- **Frontend:** HTML, CSS e JavaScript puro
- **Deploy:** Cloudflare Pages

## Estrutura

- `index.html` — interface do chat
- `style.css` — estilos
- `script.js` — lógica do chat (integração Supabase + Groq)

## Como rodar

Abra o `index.html` no navegador ou publique a pasta no Cloudflare Pages.
